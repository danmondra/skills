# skills

Daniel's personal agent skills. Straight from my `~/.agents` directory.

## Installation

**Claude Code (plugin):**

```bash
/plugin install danmondra-skills
```

**Any agent (editable copy):**

```bash
npx skills@latest add danmondra/skills
```
